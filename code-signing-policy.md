# Code signing policy

Free code signing for this open-source project is provided by
[SignPath.io](https://signpath.io), with a certificate issued by the
[SignPath Foundation](https://signpath.org).

## Team roles

- **Authors / Committers:** Christian Paniagua (@ChristianPC12) — writes and
  commits the source code.
- **Reviewers:** Christian Paniagua (@ChristianPC12) — reviews changes before a
  release.
- **Approvers:** Christian Paniagua (@ChristianPC12) — manually approves each
  signing request; only builds produced from this repository are approved.

All team members use multi-factor authentication (2FA) on both GitHub and
SignPath.

## What is signed

Only the official Windows release binaries of **Control de Repertorio**
(`Control de Repertorio.exe` and its distribution package), built from the
source code in this repository, are submitted for signing.

## Privacy statement

This program will not transfer any information to other networked systems unless
specifically requested by the user. Any media the user downloads (via `yt-dlp`)
is stored only on the user's own computer. Configuration and logs are kept
locally in the user's data folder.
